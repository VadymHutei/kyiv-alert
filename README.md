# Kyiv Alert

Kyiv Alert — сервіс сповіщень про появу та зняття **червоного рівня повітряної
загрози в місті Києві** на основі даних [NEPTUN](https://neptun.in.ua/).

Повідомлення можна отримувати в Telegram. Сервіс відстежує зміни стану, уникає
повторних сповіщень і відновлює роботу після перезапуску. Для ознайомлення та перевірки
передбачений режим із симульованими даними.

Проєкт призначений для самостійного розгортання й підтримує Docker.
Київська область та її райони не входять до поточного покриття.

Інструкції з налаштування, запуску, тестування та зберігання секретів —
у [документації](docs/OPERATIONS.md).

Це додатковий інформаційний сервіс. Орієнтуйтеся на офіційні сигнали повітряної
тривоги: дані можуть надходити із затримкою, а зняття червоного рівня не означає
відсутності всіх інших загроз.

Код поширюється за [ліцензією Apache 2.0](LICENSE).
